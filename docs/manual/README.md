## Reglas básicas
1. Use **siempre** la verificación en dos pasos y no comparta su usuario.
2. Todo lo que propone la inteligencia artificial es un **borrador**: revíselo antes de usarlo. **Las decisiones de
   avanzar, descartar o contratar las toma siempre una persona.**
3. Registre solo información **profesional** del candidato. Nunca pregunte ni anote edad, estado civil, hijos,
   religión, salud, origen ni afiliación política o sindical.
4. Las descargas y exportaciones quedan registradas: hágalas solo cuando el proceso lo requiera.
5. Ante cualquier sospecha de acceso indebido, avise de inmediato a administración.

## Glosario
| Término | Significado |
|---|---|
| Requisición | Solicitud formal de personal de un cliente |
| Vacante | Puesto publicado a partir de una requisición |
| Postulación | Participación de un candidato en una vacante |
| Perfil curricular | Datos profesionales extraídos del CV, revisados y **confirmados** por una persona |
| Matriz de cumplimiento | Estado de cada requisito: confirmado, parcial, incumplimiento documentado o información insuficiente |
| Terna | Comparativo de 2 a 6 candidatos finalistas para el cliente |
| Seudonimización | Reemplazo de nombre y datos de contacto por marcadores antes de usar la IA |
| Verificación en dos pasos | Código de 6 dígitos de una aplicación del celular, además de la contraseña |

> Las capturas de pantalla se agregarán con datos ficticios durante la capacitación.
